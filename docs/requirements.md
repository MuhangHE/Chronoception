# Chronoception 需求

柳比歇夫式时间记录：记下每段时间做了什么、从几点到几点。用起来只有三步：写（或说）一件事，开始，结束。其余都在后台完成，不打扰。

## 约束

- iPhone：iOS 26.0 起，测试机 iPhone 13 Pro。没有 Apple Intelligence，不用端侧大模型。
- 手表：watchOS 26.0 起，测试机 Apple Watch SE 第 2 代（最高只到 watchOS 26），部署目标不能再调高。
- 免费 Apple ID 签名：没有 iCloud、没有远程推送（本地通知可以），每 7 天重新签名（数据保留）。
- MiniMax API key 在 app 内输入，存进钥匙串，绝不进仓库。
- 目标：连续记录一个月。
- 数据模型和逻辑放在 `ChronoceptionKit`，能在 Mac 上用 `swift test` 测试。

## R1 开始和结束（核心）

- iPhone 底部是一个开始栏：写一句话（键盘上的麦克风也能说），点开始，立刻进入计时，这句话就是标题。
- 正在计时的事置顶显示，计时从 0 开始，旁边是「结束」。
- 有事在进行时再开始一件新的，会自动结束前一件。
- 点了结束就一定留下记录，最短算 1 分钟。

## R2 后台整理

- 开始后，MiniMax 在后台把写的话整理成简洁标题，比如「嗯现在开始写论文第三章」变成「写论文第三章」。
- 话里明确说了更早的开始时间（「九点就开始了」），就把开始时间改过来，上一件事的结束时间也跟着调。
- 不弹卡片、不需要确认。手动改过的标题或时间，后台不再改动。
- 原话保留。没网、没填 key 时照常记录，联网后自动补做整理。

## R3 手动补录与修改

- 只在时间线的空档里补录（点空档，起止时间已填好）。
- 点记录可编辑标题和时间；左滑删除，右滑拆分。
- 忘了点结束时，编辑正在进行的事，关掉「进行中」，补上结束时间。

## R4 时间线

- 按时间顺序列出一天的记录，没记录的时段显示为空档。
- 顶部显示当天已记录和未记录的总时长。
- 可以往前翻看前几天。

## R5 分类

- 不做分类。事情直接用标题记录。

## R7 提醒（待做）

- 空档超过 90 分钟时本地通知提醒，点开直接开始一件事；23:00–07:00 免打扰。
- 签名到期前一天提醒重新安装。

## R8 设置与数据

- 设置里可以导出全部记录：JSON（完整数据）和 CSV（表格）。
- 从导出文件恢复（待做）。

## R9 时间感训练（最后做）

- 补录一段时间时先猜「花了多久」，再和实际时长对比，长期统计估计偏差。

## R10 手表

- 只有三步：打开 app，点麦克风说一件事，开始；之后点结束。
- 和手机同步：手机是总账本。手表上开始、结束立刻显示，并发给手机；手机上开始、结束（以及整理后的标题）同步到手表。
- 手机不在身边时，手表的操作先排队，连上后按顺序补发；同一操作送到两次只算一次。
